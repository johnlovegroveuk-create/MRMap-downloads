MRMap 0.3.1

Released 25 October 2026 · Android 8.0 or later · 49.6 MB

Download for Android

Requires an MRMap radio number and password from your team’s administrator.

What’s changed

  • Checks for app updates when opened, with a manual check in Settings.
  • Adds a permanent download page link.
  • Uses a permanent release signing key for future updates.
  • Includes restricted team passwords, automatic air services and the Mountain Rescue app icon.

Installing and updating

  1. Download the APK using the button above.
  2. Open the downloaded file. If prompted, allow your browser to install this app.
  3. Approve installation, then open MRMap.

If you installed an earlier test build, uninstall it once before installing this release. You will need to sign in again.

Future releases signed with this release key can install over this version.

Getting access

Your team’s MRMap administrator supplies your radio number and app password.

The app supports restricted access to selected teams. Keep using the password supplied for your own radio number.
